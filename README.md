## Work in progress ##
This project is a work in progress. It's a starter project that handles API boilerplate code for configuration and JWT integration, account login, registration, and update systems, and refresh tokens. This readme will be updated when the project is finished.

### Roadmap:
* API boilerplate, CORS configuration, JWT configuration, general Program.cs setup [Done]
* Account Login, Registration, and Updating systems [Done]
* Refresh token handling [Done]
* Logging system [Done]
* Account confirmation with email service
* Password reset system
* Simple frontend form with API client
* Unit test design and implementation
